# 维护经验

- 保留 Word 式直接编辑。点击条目后通过按钮新增、复制、整条删除与排序，不能要求用户改填另一套表单。
- 输入尚未失焦就执行结构操作时，先同步最新正文；结构撤销应恢复选中条目。避免重绘正在输入的 DOM。
- 不把空模块当成首次使用后重新填三条；隐藏模块、额外表格列、自定义日期和学位必须保留。
- 个人信息的值继续留在本地，通用标签和已知占位文字另做本地英文转换。该处理也覆盖已有英文稿恢复／导入。
- 浏览器草稿可以覆盖文件模板显示；更新文件不能宣称已更新用户草稿。不同域名／端口之间用 JSON 备份迁移。
- PDF 页眉页脚由浏览器打印选项控制。照片为 35 × 49 mm；长文需核对续页页边距、末尾内容和分页。
- 截图或自动化超时不等于页面功能失败；HTTP 200 也不等于浏览器交互或大陆网络验证通过。
