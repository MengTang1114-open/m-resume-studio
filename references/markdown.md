# Markdown 结构

顶层 `#` 是姓名，首个 `##` 前的行是基本信息。`##` 是栏目；经历可用 `###` 标题和要点，教育／项目可用表格。`**重点**` 可保留，原始 HTML 会作为文字处理。

```markdown
# [姓名]
联系方式：[手机号码] ｜ 邮箱：[电子邮箱]

## 教育背景
| 时间 | 学校 | 院系 | 专业 | 学位 |
| --- | --- | --- | --- | --- |
| [起止时间] | **[学校]** | [院系] | [专业] | [学位] |

## 项目经历
### [项目名称] | [本人角色]
- [实际行动与交付物；有证据时再写结果]

## 工作经历
### [机构] | [岗位] | [时间]
- [本人负责的工作]

## 技能及爱好
**技能：** [能够实际使用的工具或能力]
```

表格内部的字面竖线请使用全角 `｜`，避免增加列。不要把占位内容当成真实经历。英文使用 `# [YOUR NAME]`、`Phone:`、`Email:` 及对应英文栏目。

中文／英文 Markdown 只替换相应语言；照片、隐藏模块和历史需用网站 JSON 备份迁移。不要手工拼造网站备份格式。
